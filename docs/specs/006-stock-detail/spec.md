# 006-股票详情 · 需求规格

> Spec 状态：`approved`
> 版本：v1.0
> 日期：2026-10-30

## 一、需求

股票详情页在移动端以卡片分区展示单只股票的全部数据，并提供「每个指标可查看来源与多源对比」的能力。

## 二、页面分区

| 分区 | 内容 |
|---|---|
| 头部 | 股票名称、代码、交易所、当前价、涨跌额、涨跌幅（涨红跌绿） |
| 基础行情 | 今开、昨收、最高、最低、成交量、成交额、换手率、量比、振幅 |
| 估值 | PE-TTM、静态PE、动态PE、PB、PS-TTM、总/流通市值 |
| 股息 | 股息率TTM、每股分红（TTM/年度）、股利支付率 |
| 财务 | 营收、营收同比、净利润、归母净利润、归母净利润同比、EPS、ROE、ROA、毛利率、净利率、资产负债率 |
| 技术指标 | 60日高/低、是否创新高/新低、近3天创60日新低、均线、周线指标（待确认的显示「待配置计算公式」） |
| 历史走势 | 价格 / PE / 股息率折线图，支持 1年/3年/5年/全部 |
| 分红记录 | 年度、每股现金分红、登记日、除息日、派息日、状态 |
| 数据来源 | 每个指标可点开，显示来源、原始值、dataTime、fetchTime、其他源对比 |

## 三、关键需求

| 编号 | 需求 |
|---|---|
| FR-6.1 | 每个指标值必须携带 `source / dataTime / fetchTime / status` |
| FR-6.2 | 点击指标弹出「数据来源」浮层，展示该指标所有已绑定数据源的取值与差异 |
| FR-6.3 | `calculationStatus = PENDING` 的指标不显示数值，显示「待配置计算公式」 |
| FR-6.4 | 亏损股的 PE 不显示数值，显示「亏损」标签，且不参与低 PE 排序 |
| FR-6.5 | 数据缺失显示「—」，不得显示 0 |
| FR-6.6 | 图表必须在小程序 canvas 2d 下渲染，不可用 Web DOM 方案 |

## 四、非功能需求

| 项 | 要求 |
|---|---|
| 首屏 | 基础行情优先返回，其余指标异步补齐（避免一次请求过重） |
| 缓存 | 同一股票 60s 内重复进入不重复打上游 |
| 可追溯 | 任一数值都能追溯到来源与时间 |
