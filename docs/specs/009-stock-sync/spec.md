# 009-全市场股票同步 · 需求规格

> Spec 状态：`approved`（实现完成后补记，与代码一致）
> 版本：v1.0
> 日期：2026-10-30

## 一、需求

后端每日定时把全市场 A 股的基础信息、行情与已绑定指标同步入库，作为市场列表、详情页与指标计算的原始数据来源。

## 二、功能需求

| 编号 | 需求 |
|---|---|
| FR-9.1 | 全市场股票清单同步：主源东方财富，失败回退新浪；保留手动全量/增量入口 |
| FR-9.2 | 行情同步：腾讯批量接口（GBK），一次 100 只 |
| FR-9.3 | 指标同步：东方财富单股快照一次返回全部绑定指标（有界并发 6） |
| FR-9.4 | 同步任务可审计：主任务 + 明细表记录每只股票/每个指标的成功与失败 |
| FR-9.5 | 失败可精准重试：按任务或按失败明细重试 |
| FR-9.6 | 定时任务每天 04:00（北京时间）执行；开关与 cron 可配置 |
| FR-9.7 | 任务锁防并发：锁超时自动释放（服务异常退出无需人工清锁） |
| FR-9.8 | 同一批行情结果同时写入 stock_quotes、stock_metric_values、stock_daily_metrics（每日留痕） |

## 三、业务规则

- 股票清单最小条数校验（min-stock-count=3000），低于阈值判定同步失败。
- 指标缺失返回 MISSING，禁止 0/估算值填充。
- 新增/更新/跳过计数口径见 design.md。
- 迁移表只新增（V4），不修改 V1~V3。

## 四、非功能需求

| 项 | 要求 |
|---|---|
| 限流 | 东财列表 300ms/页、指标 150ms/次；腾讯批量重试 3 次 |
| 可靠性 | 请求重试 + 东财快照熔断（连续 30 次失败熔断 3 分钟） |
| 可观测 | data_sync_logs / stock_sync_task(_detail) 全链路可追溯 |
