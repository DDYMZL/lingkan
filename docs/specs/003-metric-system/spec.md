# Spec 003 — 指标中心（系统核心）

- 编号：003
- 状态：**approved**
- 版本：v1.0

## 1. 需求

指标中心是整个系统的核心。所有可展示的数据项都是"指标"，指标的行为由**元数据 + 用户偏好**共同决定。

### 1.1 指标元数据（系统级，所有用户共享）

| 字段 | 说明 |
|---|---|
| `metric_code` | 唯一编码，如 `pe_ttm` |
| `metric_name` | 默认名称 |
| `metric_category` | basic / quote / valuation / dividend / financial / technical |
| `data_type` | DECIMAL / PERCENT / BOOLEAN / STRING / DATE |
| `unit` | 单位（元、%、倍、手…） |
| `calculation_type` | SOURCE（源直取）/ CALCULATED（系统计算）/ DERIVED |
| `calculation_expression` | 计算公式（人可读） |
| `calculation_status` | **READY / PENDING / DISABLED** |
| `default_precision` | 默认小数位 |
| `pending_questions` | 待确认口径问题清单 |

### 1.2 用户偏好（用户级）

每个指标支持：启用/停用、自定义显示名、展示顺序、小数位数、单位、数据来源、是否展示在首页/自选/详情、是否参与筛选、是否参与排序、是否记录历史。

### 1.3 指标库范围（74 项）

- 基础信息 5：股票代码、名称、交易所、行业、上市日期
- 实时行情 14：最新价、涨跌幅、涨跌额、开高低收、昨收、成交量、成交额、换手率、量比、振幅、总市值、流通市值
- 估值 6：PE-TTM、静态 PE、动态 PE、PB、PS-TTM、EV/EBITDA
- 股息 5：股息率 TTM、静态股息率、每股分红 TTM、最近年度每股分红、股利支付率
- 财务 14：营收、营收同比、净利润、净利润同比、归母净利润、利润同比、扣非同比、EPS、ROE、ROA、毛利率、净利率、资产负债率、经营现金流
- 技术 18 + 用户指定 6：60日最高/最低、60日新高/低、近3天创新低/新高、MA5/10/20/60、30周/60周均线、RSI、MACD、布林上/中/下轨、带内位置、周30、周中、周60、周下、周上

### 1.4 用户特别指定指标（必须原样保留）

`近3天创60日新低`、`利润同比`、`周30`、`周中`、`周60`、`周下`、`周上`、`带内位置`。

其中后 6 项 + 近3天创60日新低 初始状态为 **PENDING**，公式确认后再实现。

## 2. 核心规则

1. **PENDING 指标不得输出数值**：`MetricValueService` 第一道判断即拦截，返回 `status=PENDING` + 待确认原因。
2. **禁止 AI 自行编造公式**：`pending_questions` 明确列出需要用户回答的问题。
3. **指标不可写死**：前端不包含任何指标 code 常量列表（除默认展示顺序的初始值），全部来自 `/metrics`。
4. **配置持久化**：用户偏好存 `user_metric_preferences`，保留 `user_id` 维度。
5. **公式变更需版本化**：计算类指标的 `calculation_version` 记录在指标值表。

## 3. 已确认公式（READY）

| 指标 | 公式 | 边界处理 |
|---|---|---|
| PE-TTM | 当前总市值 ÷ 最近四个季度归母净利润之和 | 净利润<0 标记亏损不参与低 PE 排名；=0 不可计算；不足 4 季不可计算 |
| 股息率 TTM | 过去 12 个月已实施每股现金分红之和 ÷ 当前股价 × 100% | 未实施分红不计入；送股转增不计入；超过一年不计入 |
| 利润同比 | (本期归母净利润 − 上年同期) ÷ abs(上年同期) × 100% | 上年同期=0 不可计算；为负按绝对值；财报未披露→MISSING |
| 营收同比 | 同上口径（营收） | 同上 |
| 股利支付率 | (每股现金分红 × 总股本) ÷ 归母净利润 × 100% | 净利润≤0 不可计算 |
| 带内位置 | (价格 − 下轨) ÷ (上轨 − 下轨) × 100% | 上下轨相等不可计算 |

## 4. 待确认公式（PENDING）

| 指标 | 待确认问题 |
|---|---|
| 近3天创60日新低 / 新高 | ①最低价还是收盘价 ②60日窗口是否含当天 ③复权与否 ④近3天是自然日还是交易日 ⑤出现一次即可还是需连续3天 |
| 周30 / 周60 | 是否分别等于 30 / 60 周收盘价简单移动平均 |
| 周中 / 周上 / 周下 | 是否为周线布林中轨/上轨/下轨；N、K 取值 |
| 带内位置 | 使用日线还是周线布林；"当前价格"用最新价还是收盘价 |

**建议初始方案**（未确认前不实现）：交易日 + 不复权日线最低价 + 比较前 60 个有效交易日 + 最近 3 个交易日内出现过一次即为 true。
