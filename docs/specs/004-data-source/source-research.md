# 数据源研究报告（Phase 1）

> 文档版本：v1.0
> 测试日期：2026-10-30
> 测试环境：Windows，JDK 未参与（使用 HTTP 直连测试），网络可直连境内金融站点
> 测试方法：直接向候选接口发起 HTTP 请求，记录状态码、耗时、返回样本；**未使用任何第三方文章结论代替实测**

## 一、测试结论总览

| 数据源 | 实测状态 | 是否可用于取数 | 结论 |
|---|---|---|---|
| 东方财富 | HTTP 200，多个接口均通 | ✅ 可用（行情/列表/历史K线/分红/财报） | 作为主数据源之一 |
| 腾讯财经 | HTTP 200，支持批量 | ✅ 可用（批量实时行情） | 作为实时行情首选源 |
| 新浪财经 | HTTP 200（需 Referer） | ✅ 可用（行情辅助验证） | 默认停用，作交叉验证 |
| 巨潮资讯 | HTTP 200，返回公告列表 | ⚠️ 部分可用（非结构化） | 待做财报字段解析后接入 |
| 乐咕乐股 | HTTP 404（多个路径） | ❌ 不可用 | 历史股息率来源待重新确认 |
| Tushare | HTTP 200，code=40101 需 Token | ⚠️ 待授权 | 需申请 Token 并确认积分权限 |
| AKShare | 上游接口可达，库本身为 Python | ⚠️ 需采集容器 | Phase 4 以独立容器接入 |
| BaoStock | 官网可达，SDK 为 Python | ⚠️ 需采集容器 | 适合历史行情，Phase 4 评估 |

关键结论：**第一版能够稳定支撑"实时行情 + 股票列表 + 历史K线 + 分红 + 财报原始数据"的数据源是东方财富与腾讯财经**；股息率、PE-TTM 这类衍生指标应全部由系统按已确认公式自行计算，而不是依赖某个"股息率接口"。

**实测样本（贵州茅台 600519）**

```
单股快照: {"rc":0,...,"data":{"f43":139205,"f44":139337,"f45":135298,"f46":136300,
"f47":59927,"f48":8257381778.0,"f50":136,"f57":"600519","f58":"贵州茅台",
"f60":135400,"f116":1740176092672.05,"f117":1740176092672.05,"f162":1955,
"f167":693,"f168":48,"f169":3805,"f170":281}}
```

字段口径（经与腾讯、新浪三方交叉核对）：

| 字段 | 含义 | 换算 |
|---|---|---|
| f43 | 最新价 | ÷100 → 1392.05 |
| f44 / f45 / f46 / f60 | 最高 / 最低 / 开盘 / 昨收 | ÷100 |
| f47 | 成交量 | 手 |
| f48 | 成交额 | 元 |
| f50 | 量比 | ÷100 → 1.36 |
| f116 / f117 | 总市值 / 流通市值 | 元 |
| f167 | 市净率 | ÷100 → 6.93 |
| f168 | 换手率 | ÷100 → 0.48% |
| f169 / f170 | 涨跌额 / 涨跌幅 | ÷100 |

> 交叉核对：腾讯返回最新价 1392.05、涨跌幅 2.81%、PB 6.93，新浪返回 1392.050，三者一致。

**注意**：`f162`（实测 19.55）在不同资料中分别被称为动态 PE / TTM PE，口径存在歧义。因此本项目**不采用接口 PE，PE-TTM 一律由系统按"总市值 ÷ 最近四个季度归母净利润之和"计算**。

**周K 实测（2026-10-31，`klt=102`，供 spec 010 周线五列使用）**

```
https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.600519
  &fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58
  &klt=102&fqt=1&end=20500101&lmt=130
```

| 项 | 实测结论 |
|---|---|
| secid 规则 | 代码以 6/9 开头 → `1.<code>`（沪），其余 → `0.<code>`（深），与日线接口一致 |
| 返回结构 | `data.klines` 为**升序** CSV 字符串数组：`日期,开盘,收盘,最高,最低,成交量(手),成交额(元),振幅(%)` |
| 复权 | `fqt=1` 前复权；`adjustment_type` 落库固定 `QFQ` |
| 含本周 | 返回的最后一根为本周未收盘 bar（`trade_date` 取该周最后交易日）；当「最新周线日期」与「行情时间」同属一个 ISO 周时，本周 bar 的收盘价用实时行情价覆盖（Q7-4 裁决） |
| 窗口 | `lmt=130`：覆盖 MA120 所需的 120 根 + 缓冲；每次同步整窗口覆盖落库（前复权基准随除权漂移，不做增量合并） |
| 限流 | 复用日线接口同款 500ms/次 保守限流（`lingkan.board.weekly.request-interval-ms`） |

**前复权负价坑**：深度除权的老股在前复权口径下早期收盘价可能 ≤ 0，均线/布林在数学上仍算得出但经济含义失真。本项目约定：窗口内任一收盘价 ≤ 0 时，`week_60 / week_120 / week_upper / week_middle / week_lower` 全部返回 `MISSING`（前端 `--`），不用 0 或估值填充（铁律 6）。

**独立复算交叉验证**：用原始周K 在 Node 侧独立复算 MA60/MA120/布林（样本标准差），与后端看板输出逐分一致——600519：1346.11 / 1378.23 / 1397.89 / 1277.72 / 1157.56；000001：10.76 / 10.48 / 12.17 / 11.05 / 9.93。

## 四、风险与注意事项

1. **接口非官方文档化**：东方财富、腾讯、新浪均为页面背后的非公开接口，字段可能变更。适配器必须做字段缺失兜底，并记录 `raw_payload` 便于回溯。
2. **限流策略**：所有适配器统一 `request_interval_ms`（默认 500ms），后端开启同步任务前必须确认批次大小。当前 `lingkan.sync.enabled=false`。
3. **口径差异**：不同源对"PE""成交额单位（万/元）""成交量单位（股/手）"定义不一致，已在适配器中显式换算并注释。
4. **数据合规**：仅个人使用、低频访问、不对外分发数据；如上游声明限制，立即停用对应数据源。
5. **未验证项**：北交所 `secid` 规则、东方财富 `f162` PE 口径、乐咕乐股替代源 —— 均记录在 `docs/specs/004-data-source/spec.md` 的待确认清单。
