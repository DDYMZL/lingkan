# Spec 001 — 项目总览

- 编号：001
- 状态：**approved**
- 版本：v1.0（2026-10-30）

## 1. 需求

### 1.1 目标

构建个人使用的 A 股数据查询与分析微信小程序「玲看股息」，让用户**通过小程序配置指标和数据源**，而不是通过改代码来改变自己看到的数据。

### 1.2 用户与场景

| 项 | 内容 |
|---|---|
| 用户 | 单一使用者（项目作者本人） |
| 设备 | 手机（微信小程序） |
| 典型场景 | 通勤时看自选股股息率排行；筛选"股息率>4% 且 PE<15"的股票；查看某只股票近 3 年股息率走势 |
| 非目标 | 多用户注册、交易下单、PC 后台、对外开放 |

### 1.4 核心设计原则

1. **指标可配置** — 指标库统一管理，前端不写死字段。
2. **数据源可配置** — 指标与数据源多对多绑定，可切换主源。
3. **展示可配置** — 每个指标可独立设置是否显示在首页/自选/详情、精度、单位、排序。
4. **数据可追溯** — 每个数值都带来源、数据时间、采集时间、计算版本。

## 2. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 列表接口 P95 < 1.5s（含一次批量行情请求）；行情缓存 20s |
| 可用性 | 单个数据源故障不影响其他指标展示，失败降级为 `MISSING` 而非报错 |
| 数据准确性 | 不虚构数据；计算使用 BigDecimal；所有衍生指标带 `calculation_version` |
| 安全 | Token 只存服务端；小程序不直连第三方接口 |
| 可维护性 | 新增数据源 = 新增一个适配器类 + 一条 data_providers 记录，不改业务代码 |
| 可扩展性 | 新增指标 = 新增 metric_definitions 记录 + 必要时新增计算实现 |

## 4. 验收标准（整体）

1. 小程序在微信开发者工具中编译通过、页面可正常操作。
2. 后端可启动，`/actuator/health` 为 UP，openGauss 连接正常且迁移脚本执行成功。
3. 首页、市场、自选、详情页的所有数值均来自真实数据源，无 mock。
4. 修改指标配置后，列表/详情展示的字段随之变化，无需改代码。
5. 同一指标可看到至少两个来源的取值与差异。
6. 单元测试覆盖关键计算边界场景。
