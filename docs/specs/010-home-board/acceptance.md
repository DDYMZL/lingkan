# 010-首页自选看板与计算引擎 · 验收标准

> 版本：v1.2　日期：2026-10-31
> 来源：技术方案第十三节「最终验收标准」+ 第十一节「测试要求」+ 用户 2026-10-31 裁决（行业列 / 六档 / 周线五指标 / 横滚布局）

## 功能验收

1. 用户可以搜索并添加任意正常上市的 A 股（沿用现有搜索 + 自选接口）。
2. 添加的股票出现在首页看板表格，重复添加幂等。
3. 每只股票展示：现价、当天涨跌幅、现股息率、PE TTM、行业、60周、120周、周上、周中、周下。
4. 表格横向滚动且首列（名称/代码/行业）固定；表头与表体列严格对齐；点击每只股票所在行可展开/收起 4%～6.5% 共 6 档目标价格（保留两位小数、3×2 网格、档位顺序固定），行情推送不会清除展开状态；7%/7.5%/8% 三档不再出现在任何位置。
5. 行情变化后，现股息率、PE TTM 与周线五指标自动变化（15 秒内刷新，非交易时段保持最后行情并标注时间）。
6. 分红数据变化后，目标价格自动重算；行情变化不重算目标价格。
7. 财务数据变化后，PE TTM 自动重算。
8. 行情更新频率遵循数据源允许的最短合理间隔（默认 15 秒可配置，仅交易时段高频）。
9. 不同用户的自选列表互相独立（第一版单用户，结构支持扩展）。
10. 用户可以删除、排序自选股票。
11. 首页只展示自选股票：无大盘指数、资讯、板块行情、热门、资金流向、市场新闻、复杂统计卡片；行业只作为个股属性列，不提供行业分类浏览。
12. 所有计算结果均有明确的数据来源和更新时间；历史价格不得冒充实时价格；缺失值显示 `--` 而非 0。
13. 周线同步失败或周线根数不足时，只有周线五列显示 `--`，其余列照常展示；看板请求路径不产生任何上游数据源请求。
14. 「过去 5 年平均分红」「去年的分红」不出现在界面上（用户 2026-10-31 明确不做）。

## 计算正确性验收（以单元测试为准）

| 场景 | 期望 |
|---|---|
| 已实施分红 3 元/股，股价 50/48/55 | 股息率 6% / 6.25% / ≈5.45% |
| 目标价格（3 元/股，v1.2 六档） | 4%→75.00、4.5%→66.67、5%→60.00、5.5%→54.55、6%→50.00、6.5%→46.15 |
| PE（TTM 利润 50 亿） | 市值 500/600/400 亿 → 10 / 12 / 8 |
| TTM 利润 ≤ 0 / 缺失 | 显示 `--` / 「亏损」 |
| 12 个月窗口内外分红 | 窗口外不计入 |
| 已公告未实施 / 预案分红 | 不计入 |
| 同年度多次 / 跨年度分红 | 分别记录、分别累加 |
| 同一方案重复公告 | 按 dividend_id 去重 |
| 送转股事件 | 历史分红换算为当前股本口径后累加（10转10 → 每股分红折半） |
| 价格为空/0 | 不计算股息率与 PE，显示 `--` |
| 60 根等差周线收盘价 | `MA60` = 手算均值；59 根 → `--`（INSUFFICIENT） |
| 120 根周线 | `MA120` = 手算均值；119 根 → `--` |
| 20 根周线（已知均值与标准差） | 周中 = MA20；周上 = 周中 + 2×样本标准差；周下 = 周中 − 2×样本标准差 |
| 周线收盘价含 0 或负值 | 该窗口指标全部 `--`（前复权负价防护） |
| 本周未收盘 + 同 ISO 周行情 | 本周收盘价被实时价覆盖，指标随价变化 |
| 最新周线属上一 ISO 周 | 不覆盖，指标按库内周线计算 |
| 行业字段为空 | 行业列 `--`，不填「其他」 |

## 行情与交互验收

- 股价上涨/下跌/不变、行情接口超时、停牌、非交易时间均有明确表现（单元/手动）。
- WebSocket 断开自动重连，重连后重新获取完整快照；WS 不可用时首页仍正常展示（HTTP 兜底）。
- 多个用户同时查看同一只股票共享同一份行情缓存。
- 50 只自选股看板接口 P95 < 1.5s（周线批量一次查询，无 N+1）；WS 推送只更新变化行，不整页重渲染。
- 小程序切后台暂停连接、回前台重新拉快照、页面退出释放连接。
- 横向滚动时首列保持可见、表头保持可见，滚动不错位（开发者工具 + 真机各验一次）。
