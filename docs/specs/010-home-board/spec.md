## 一、需求

将现有首页调整为**个人自选股票监控看板**。用户添加自选后，首页以表格形式展示：

1. 股票当前价格与当天涨跌幅；
2. 当前股息率（随实时价格动态计算）；
3. PE TTM（市盈率）；
4. 4%～8% 共 9 档目标股息率对应的股价。

本项目不是综合股票行情软件。首页**不展示**大盘指数、财经资讯、行业板块、热门股票、资金流向、市场新闻、复杂统计卡片。

## 二、功能需求

| 编号 | 需求 |
|---|---|
| FR-10.1 | 首页以极简表格展示自选股票，默认 15 列，列顺序固定：股票名称、股票代码、现价、涨跌幅、现股息率、PE TTM、4%/4.5%/5%/5.5%/6%/6.5%/7%/7.5%/8% 目标价格 |
| FR-10.2 | 现股息率 = 最近 12 个月已实施每股现金分红总额 ÷ 当前股价 × 100%，随行情价格自动变化 |
| FR-10.3 | PE TTM = 当前总市值 ÷ 最近 12 个月归母净利润，随行情价格自动变化 |
| FR-10.4 | 目标价格 = 最近 12 个月每股已实施现金分红 ÷ 目标股息率（保留两位小数）；无有效分红时返回 `--` |
| FR-10.5 | 目标价格仅在分红实施、TTM 窗口变化、股本变化、分红数据修正时重算；行情变化不触发目标价格重算 |
| FR-10.6 | 搜索并添加任意正常上市的 A 股到自选；重复添加幂等 |
| FR-10.7 | 支持删除、排序自选（沿用现有 `/api/v1/watchlist` 能力） |
| FR-10.8 | 行情自动刷新：后端统一轮询（默认 15 秒、仅交易时段、可配置），多用户共享同一份行情缓存，小程序不直连行情接口 |
| FR-10.9 | WebSocket 推送自选股行情更新；断开后自动重连并重新拉取完整快照；WS 不可用时 HTTP 查询兜底，首页正常展示 |
| FR-10.10 | 首页只展示自选股票；未添加时显示空状态引导（不推荐无关股票） |
| FR-10.11 | 所有计算结果携带数据来源与数据时间；行情更新时间在首页可见，历史价格不得冒充实时价格 |

## 三、业务规则

### 3.1 股息率 TTM 口径

- 统计范围：以计算时点 T 往前推 12 个月，按**实际派息实施日期**筛选（`implementation_date`），缺失时用除息日（`ex_dividend_date`）兜底。
- 只统计**已实施**的现金分红；预案、已公告未实施、取消的分红不计入。
- 不计算送股、资本公积转增、股票回购。
- 同一分红方案多条公告按方案唯一标识（`dividend_id`）去重。
- 年度、中期、特别、跨年度、同年度多次分红分别记录、分别计算。

### 3.2 股本变化换算（第一版必须实现）

- 分红之后发生送股、转增、拆股、并股等影响每股权益的事项时，历史每股现金分红统一换算为**当前股本口径**后再累加。
- 换算依据 `stock_share_events` 股本变动事件表（新增），事件数据来自东方财富分红送配接口中的送转股字段。
- 换算因子：分红除息日之后发生的送/转（每 10 股送/转 X → 每股变 1+X/10 股）按 1/(1+X/10) 折减；拆股（1 拆 N）按 1/N；并股（N 并 1）按 N。
- 事件日期与分红除息日同日的，视为影响该笔分红（同日送转按除息前股本派息）。
- 只统计现金分红，送转股本身不作为现金收益。

### 3.3 PE TTM 规则

- 公式：当前总市值 ÷ 最近四个连续季度归母净利润之和（优先市值口径，避免累加 EPS 的加权股本误差）。
- TTM 净利润 > 0 → 正常计算；= 0 → 显示 `--`；< 0 → 显示「亏损」（不显示负数 PE，不参与低 PE 排序）；财务数据缺失 → `--`；财务数据过期 → 显示旧值并标记数据时间。

### 3.4 数据准确性

| 场景 | 处理 |
|---|---|
| 当前价格为空/为 0 | 不计算股息率和 PE，显示 `--` |
| 最近 12 个月无已实施分红 | 股息率与目标价格显示 `--`（禁止用 0 填充） |
| 财务数据缺失 | PE 显示 `--` |
| TTM 利润为负 | PE 显示「亏损」 |
| 分红重复记录 | 按 `dividend_id` 去重 |
| 行情接口失败 | 保留最近有效行情并标记过期 |
| 财务/分红同步失败 | 保留最近有效数据 |
| WebSocket 断开 | HTTP 重新获取完整快照 |
| 股票停牌 | 显示最后有效价格及停牌状态 |

所有金额计算使用 `BigDecimal`。所有数据保留 `data_time`（数据所属时间）与 `fetch_time`（采集时间）与来源。

## 四、非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 50 只自选股看板接口 P95 < 1.5s（依赖行情缓存） |
| 更新频率 | 行情轮询默认 15 秒可配置，仅交易时段高频；频率以数据源实际限速为准 |
| 隔离 | 不同用户自选互相独立（沿用 `user_id` 维度，第一版单用户 `local-user`） |
| 降级 | 单数据源失败不阻塞整页；WS 断开不影响展示 |
