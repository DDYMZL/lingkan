## 一、需求

将现有首页调整为**个人自选股票监控看板**。用户添加自选后，首页以表格形式展示：

1. 股票当前价格与当天涨跌幅；
2. 当前股息率（随实时价格动态计算）；
3. PE TTM（市盈率）；
4. 所属行业；
5. 周线技术价位：60周均线、120周均线、周线布林上轨/中轨/下轨；
6. 4%～6.5% 共 6 档目标股息率对应的股价（行内展开）。

本项目不是综合股票行情软件。首页**不展示**大盘指数、财经资讯、行业板块行情、热门股票、资金流向、市场新闻、复杂统计卡片。行业仅作为个股的静态属性列展示，不做行业分类浏览或行业涨跌统计。

## 三、业务规则

### 3.1 股息率 TTM 口径

- 统计范围：以计算时点 T 往前推 12 个月，按**实际派息实施日期**筛选（`implementation_date`），缺失时用除息日（`ex_dividend_date`）兜底。
- 只统计**已实施**的现金分红；预案、已公告未实施、取消的分红不计入。
- 不计算送股、资本公积转增、股票回购。
- 同一分红方案多条公告按方案唯一标识（`dividend_id`）去重。
- 年度、中期、特别、跨年度、同年度多次分红分别记录、分别计算。

### 3.2 股本变化换算（第一版必须实现）

- 分红之后发生送股、转增、拆股、并股等影响每股权益的事项时，历史每股现金分红统一换算为**当前股本口径**后再累加。
- 换算依据 `stock_share_events` 股本变动事件表（新增），事件数据来自东方财富分红送配接口中的送转股字段。
- 换算因子：分红除息日之后发生的送/转（每 10 股送/转 X → 每股变 1+X/10 股）按 1/(1+X/10) 折减；拆股（1 拆 N）按 1/N；并股（N 并 1）按 N。
- 事件日期与分红除息日同日的，视为影响该笔分红（同日送转按除息前股本派息）。
- 只统计现金分红，送转股本身不作为现金收益。

### 3.3 PE TTM 规则

- 公式：当前总市值 ÷ 最近四个连续季度归母净利润之和（优先市值口径，避免累加 EPS 的加权股本误差）。
- TTM 净利润 > 0 → 正常计算；= 0 → 显示 `--`；< 0 → 显示「亏损」（不显示负数 PE，不参与低 PE 排序）；财务数据缺失 → `--`；财务数据过期 → 显示旧值并标记数据时间。

### 3.4 数据准确性

| 场景 | 处理 |
|---|---|
| 当前价格为空/为 0 | 不计算股息率和 PE，显示 `--` |
| 最近 12 个月无已实施分红 | 股息率与目标价格显示 `--`（禁止用 0 填充） |
| 财务数据缺失 | PE 显示 `--` |
| TTM 利润为负 | PE 显示「亏损」 |
| 分红重复记录 | 按 `dividend_id` 去重 |
| 行情接口失败 | 保留最近有效行情并标记过期 |
| 财务/分红同步失败 | 保留最近有效数据 |
| WebSocket 断开 | HTTP 重新获取完整快照 |
| 股票停牌 | 显示最后有效价格及停牌状态 |
| 行业字段缺失 | 行业列显示 `--`（不填「其他」、不推断） |
| 周线根数不足（< 60 / < 120 / < 20） | 对应指标显示 `--`，并记录 `weeklyStatus = INSUFFICIENT` |
| 周线接口失败或未同步 | 五个周线指标全部 `--`，`weeklyStatus = MISSING`，不影响其余列 |
| 周线收盘价出现非正值 | 视为数据异常，该窗口指标 `--`（前复权对高分红老股会产生负价，见 §3.5） |

所有金额计算使用 `BigDecimal`。所有数据保留 `data_time`（数据所属时间）与 `fetch_time`（采集时间）与来源。

### 3.5 周线指标口径（v1.2 新增，用户 2026-10-31 确认）

对应 spec 007 的待确认项 Q7-2 / Q7-3 / Q7-4 / Q7-6 / Q7-7 / Q7-8，本次全部裁决如下：

| 项 | 结论 |
|---|---|
| 60周 | `MA(周线收盘价, 60)`，与既有 `ma_60w` 同口径；登记项 `week_60` 转 `READY` |
| 120周 | `MA(周线收盘价, 120)`；**新增**登记项 `week_120`（既有指标库无此项） |
| 周中 | 周线布林中轨 `MA(周线收盘价, 20)` |
| 周上 | 周中 `+ 2 × STD(周线收盘价, 20)` |
| 周下 | 周中 `− 2 × STD(周线收盘价, 20)` |
| N / K | 默认 N=20、K=2，落在配置 `lingkan.board.weekly.boll-n` / `boll-k`，改数值不改代码 |
| 均线周期 | 配置 `lingkan.board.weekly.ma-short`（60）/ `ma-long`（120） |
| 标准差口径 | **样本标准差（除以 N−1）**，对齐通达信/同花顺 `STD`；若后续与用户参照软件出现偏差，改口径需提升 `calculation_version` |
| 周线切分 | 直接采用东财周 K 接口返回的周线（`klt=102`），**不自行按自然周聚合日线**（Q7-7） |
| 复权方式 | **前复权 `fqt=1`**：均线与现价同口径可比，历史送转股不断层（Q7-6 相关） |
| 当前未收盘周 | **参与计算**（Q7-8）：本周周线的收盘价用实时行情最新价覆盖，因此周线五指标随行情变化；覆盖仅在「最新周线日期与行情时间同属一个 ISO 周」时生效，避免用今天的价覆盖上周的线 |
| 数据不足 | 窗口内可用周线根数 < 指标所需根数 → 该指标 `--`（`INSUFFICIENT`），禁止用已有根数凑算 |
| 前复权负价 | 东财前复权对累计分红极大的老股会算出**负价格**（实测贵州茅台 2001 年周线前复权为 −312.68）。计算窗口内任一收盘价 ≤ 0 → 该窗口全部指标 `--`，不得输出数值 |
| 复权基准漂移 | 前复权以最新除权事件为基准，每次同步**整窗口覆盖 upsert**（默认取最近 130 根），禁止只增量追加，否则表内会混用两套复权基准 |

数据来源可追溯（铁律 4）：周线值随 `weeklyDataTime`（最新周线所属周末交易日）与 `weeklyStatus` 一并返回；采集来源为东财周 K 接口，落库 `stock_weekly_quotes`（`source_code = eastmoney`、`adjustment_type = QFQ`、`fetch_time`）。

## 四、非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 50 只自选股看板接口 P95 < 1.5s（依赖行情缓存；周线只读本地表，批量一次查询，不在请求路径访问上游） |

| 隔离 | 不同用户自选互相独立（沿用 `user_id` 维度，第一版单用户 `local-user`） |
| 降级 | 单数据源失败不阻塞整页；WS 断开不影响展示；周线同步失败只让周线五列显示 `--`，其余列正常 |
