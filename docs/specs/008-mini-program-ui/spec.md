# 008-小程序 UI 与交互 · 需求规格

> Spec 状态：`approved`
> 版本：v1.3（首页看板交互由 spec 010 v1.3 修订：十列横向滚动 + 首列固定 + 六档目标价 + 双向 scroll-view 吸顶吸左）
> 日期：2026-10-31

## 一、定位

本项目前端**只能是微信小程序**，不开发 PC 管理后台、不开发独立 Web 管理系统。

所有用户操作在微信小程序内完成。

## 二、导航结构

底部 TabBar 四个入口：

| Tab | 页面路径 | 说明 |
|---|---|---|
| 首页 | `pages/home/index` | 个人数据概览 |

|---|---|

## 三、视觉规范

| 项 | 规范 |
|---|---|
| 主题 | 深色 / 浅色可切换，跟随系统 |
| 涨跌色 | **上涨红、下跌绿、平盘中性灰**（A股习惯，不可用美股配色） |
| 卡片 | 圆角 16rpx，浅阴影，白/深灰底 |
| 字体 | 数值优先，数值字号大于标签 |
| 信息密度 | 移动端紧凑，指标双列网格 |
| 动画 | 轻量，仅刷新与展开 |

## 四、移动端布局约束

默认采用股票卡片 / 紧凑列表行、核心指标双列展示、次要指标折叠，不使用需要横向滑动的 PC 式大表格。

首页自选看板由 spec 010 定义为唯一例外视图：v1.1 曾要求默认五列不横滑；**v1.2 起列数增至十列（新增行业、60周、120周、周上、周中、周下），恢复横向滚动表格 + 首列固定**；v1.3 实现时裁决纵向滚动亦在同一 scroll-view 内（双向 scroll-view + 固定高度）——`overflow-x` 容器是 sticky 的滚动端口，表头吸顶无法相对页面级滚动生效，见 spec 010 design §7.1。其他页面维持原有移动端布局约束。

## 五、页面需求要点

### 5.1 首页

- 顶部：我的自选、自选数量、行情更新时间、刷新与添加股票按钮；连接状态仅表示 WS 通道，不替代行情时间
- 表头与表体同处一个双向滚动容器（scroll-x + scroll-y + 固定高度），**首列（名称/代码/行业）`sticky left` 固定、表头 `sticky top` 固定**、展开区 `sticky left`；默认十列：股票名称/代码（行业在代码下方小字）、现价、涨跌幅、股息率 TTM、PE TTM、60周、120周、周上、周中、周下
- 点击行展开/收起 4%～6.5% 六档目标价（3×2 网格）；展开状态不被行情推送清除
- 首页不展示排行榜、市场概览或全市场入口；全市场仅保留底部 Tab
- 所有数值必须来自真实后端快照与计算引擎；数据未就绪时显示 `--`，不得以 0 补值；行业缺失同样显示 `--`，不得推断或填「其他」
- 周线五列为价位参考线，不做涨红跌绿着色；它们的时效由后端 `weeklyDataTime` / `weeklyStatus` 标注

### 5.2 市场页

- 搜索（名称/代码）
- 交易所筛选（沪/深/北）
- 指标排序（点击指标列头）
- 指标筛选（区间条件）
- 加自选
- 跳详情
- **列表字段完全动态化**

### 5.3 指标配置页

- 按分类分组
- 勾选/取消指标
- 拖动排序
- 修改显示名、小数位数、单位
- 选择数据源
- 开关：首页/自选/详情/排序/筛选/历史
- `PENDING` 指标显示「待配置计算公式」且禁止启用计算

### 5.4 数据源配置页

- 卡片列表，展示状态、支持指标数、健康状态
- 启用/停用
- 测试连接（真实请求）
- 查看调用日志
- Token 配置（只写不读）
- **不得展示 Token 明文**

### 5.5 我的页面

指标配置、数据源配置、数据源对比、自选管理、刷新设置、数据更新记录、缓存清理、关于。

## 六、非功能需求

| 项 | 要求 |
|---|---|
| 编译目标 | `mp-weixin`，必须能用微信开发者工具打开并预览 |
| 禁止 API | 不得使用 `document` / `window` / `localStorage` 等浏览器专有 API，改用 `uni.*` |
| 错误提示 | 网络失败必须有明确提示与重试入口 |
| 缓存 | 使用 `uni.setStorageSync`，不依赖浏览器存储 |
| 分包 | 首版不强制分包，但页面数 > 10 时需评估 |
