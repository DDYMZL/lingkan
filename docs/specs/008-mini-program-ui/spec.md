# 008-小程序 UI 与交互 · 需求规格

> Spec 状态：`approved`
> 版本：v1.0
> 日期：2026-10-30

## 一、定位

本项目前端**只能是微信小程序**，不开发 PC 管理后台、不开发独立 Web 管理系统。

所有用户操作在微信小程序内完成。

## 二、导航结构

底部 TabBar 四个入口：

| Tab | 页面路径 | 说明 |
|---|---|---|
| 首页 | `pages/home/index` | 个人数据概览 |
| 市场 | `pages/market/index` | A股全市场列表 |
| 自选 | `pages/watchlist/index` | 自选股 |
| 我的 | `pages/settings/index` | 设置入口 |

非 Tab 页面：

| 页面 | 路径 |
|---|---|
| 股票详情 | `pages/stock-detail/index` |
| 指标配置 | `pages/metric-config/index` |
| 数据源配置 | `pages/datasource/index` |
| 数据源对比 | `pages/metric-compare/index` |

## 三、视觉规范

| 项 | 规范 |
|---|---|
| 主题 | 深色 / 浅色可切换，跟随系统 |
| 涨跌色 | **上涨红、下跌绿、平盘中性灰**（A股习惯，不可用美股配色） |
| 卡片 | 圆角 16rpx，浅阴影，白/深灰底 |
| 字体 | 数值优先，数值字号大于标签 |
| 信息密度 | 移动端紧凑，指标双列网格 |
| 动画 | 轻量，仅刷新与展开 |

## 四、移动端布局约束

**不使用 PC 式横向大表格。** 原因：小程序屏宽 375pt，横向表格需滑动且不可读。

采用：

- 股票卡片 / 紧凑列表行
- 核心指标双列展示
- 次要指标折叠
- 必要时横向滑动指标区（仅在详情页多指标场景）

## 五、页面需求要点

### 5.1 首页

- 顶部：Logo、交易状态、行情更新时间、刷新按钮
- 自选概览：自选股数量 + 前 N 只的精选指标
- 排行榜：高股息率 / 低 PE / 利润同比 / 60日新低，**排行榜指标由用户配置决定**
- 市场概览：股票总数、上涨/下跌/平盘数、更新时间
- 所有统计必须来自真实数据；数据未就绪时显示「暂无数据」而非 0

### 5.2 市场页

- 搜索（名称/代码）
- 交易所筛选（沪/深/北）
- 指标排序（点击指标列头）
- 指标筛选（区间条件）
- 加自选
- 跳详情
- **列表字段完全动态化**

### 5.3 指标配置页

- 按分类分组
- 勾选/取消指标
- 拖动排序
- 修改显示名、小数位数、单位
- 选择数据源
- 开关：首页/自选/详情/排序/筛选/历史
- `PENDING` 指标显示「待配置计算公式」且禁止启用计算

### 5.4 数据源配置页

- 卡片列表，展示状态、支持指标数、健康状态
- 启用/停用
- 测试连接（真实请求）
- 查看调用日志
- Token 配置（只写不读）
- **不得展示 Token 明文**

### 5.5 我的页面

指标配置、数据源配置、数据源对比、自选管理、刷新设置、数据更新记录、缓存清理、关于。

## 六、非功能需求

| 项 | 要求 |
|---|---|
| 编译目标 | `mp-weixin`，必须能用微信开发者工具打开并预览 |
| 禁止 API | 不得使用 `document` / `window` / `localStorage` 等浏览器专有 API，改用 `uni.*` |
| 错误提示 | 网络失败必须有明确提示与重试入口 |
| 缓存 | 使用 `uni.setStorageSync`，不依赖浏览器存储 |
| 分包 | 首版不强制分包，但页面数 > 10 时需评估 |
