## 一、需求

系统需保存历史行情与历史指标，支持趋势图与「近 N 日新高/新低」类技术判断。

## 二、历史数据

| 编号 | 需求 |
|---|---|
| FR-7.1 | 保存不复权日线（`adjustment_type = NONE`），按 `(stock_id, trade_date, adjustment_type, source_code)` 唯一 |
| FR-7.2 | 每个交易日收盘后生成指标日快照到 `stock_daily_metrics` |
| FR-7.3 | 历史数据**不得覆盖**，重算时保留 `calculation_version` |
| FR-7.4 | 支持按指标 + 时间范围查询序列（1年/3年/5年/全部） |
| FR-7.5 | 序列每个点必须能追溯到 `source_code` |

## 三、技术指标

### 3.1 已明确的指标

| metricCode | 名称 | 规则 |
|---|---|---|
| `low_60d` | 60日最低价 | 最近 60 个交易日（含当日）的最低价最小值 |
| `high_60d` | 60日最高价 | 同上取最大 |
| `new_low_60d` | 是否创60日新低 | 当日最低价 ≤ 前 59 个交易日最低价的最小值 |
| `new_high_60d` | 是否创60日新高 | 当日最高价 ≥ 前 59 个交易日最高价的最大值 |
| `new_low_60d_3d` | 近3天创60日新低 | 见 3.2 |
| `return_5d/20d/60d` | N日涨跌幅 | (今收 − N交易日前收) ÷ N交易日前收 × 100 |

### 3.2 `new_low_60d_3d`（近3天创60日新低）

原文档给出的待确认项与建议默认值，本项目**采用建议默认值实现，但标记为 `review` 状态，需用户确认后转 `approved`**。

采用的默认口径：

| 项 | 采用值 | 原文档待确认项 |
|---|---|---|
| 价格字段 | **不复权日线最低价** `low_price` | 「最低价还是收盘价」「复权还是不复权」 |
| 比较窗口 | 当日之前的 **60 个有效交易日**（不含当日） | 「60日是否包含当天」 |
| 近期范围 | 最近 **3 个交易日** | 「自然日还是交易日」 |
| 触发条件 | 3 日内**任一日**出现即 true（OR） | 「出现过一次，还是连续3天」 |
| 数据不足 | 可用交易日 < 61 时返回 `status = INSUFFICIENT_DATA` | — |
| 当日未收盘 | 返回 `status = PROVISIONAL`（临时结果） | — |

计算伪代码：

```text
bars = 最近 63 个交易日日线（升序，最后一条为最新）
if (bars.size < 61) return INSUFFICIENT_DATA

for i in [bars.size-3, bars.size-1]:
    cur = bars[i].lowPrice
    window = bars[i-60 .. i-1].lowPrice       // 严格不含当日
    ref = min(window)
    if (cur <= ref) return TRUE
return FALSE
```

> ⚠️ **必须由用户确认的 5 个问题**（原文档 8.4 节）：
> 1. 用最低价还是收盘价？
> 2. 60 日窗口是否包含当天？
> 3. 复权还是不复权？
> 4. 最近 3 天是自然日还是交易日？
> 5. 出现过一次即可，还是要求连续 3 天？
>
> 当前实现按上表默认值，**任一项变更都需要同步修改计算器与 acceptance.md**。

| 编号 | 问题 | 结论 |
|---|---|---|
| Q7-1 | 「周30」是否 = 30 周简单移动平均线？ | **未确认**，`week_30` 保持 `PENDING`，本轮不实现 |
| Q7-2 | 「周60」是否 = 60 周简单移动平均线？ | **是**：`MA(周线收盘价, 60)`，与既有 `ma_60w` 同口径；`week_60` 转 `READY` |
| Q7-3 | 「周中」是否 = 周线通道中轨（布林中轨，N=20，K=2）？ | **是**：`MA(周线收盘价, 20)`；`week_middle` 转 `READY` |
| Q7-4 | 「周上」「周下」是否 = 布林上轨/下轨？ | **是**：`周中 ± 2 × STD(周线收盘价, 20)`；`week_upper`/`week_lower` 转 `READY` |
| Q7-5 | 「带内位置」是否 = (现价 − 周下轨) ÷ (周上轨 − 周下轨) × 100？ | **未确认**，`band_position` 保持 `PENDING`，本轮不实现 |
| Q7-6 | N 与 K 是否需要用户可配置？默认 20 / 2？ | **默认 N=20、K=2**，落在配置 `lingkan.board.weekly.boll-n` / `boll-k`，改数值不改代码 |
| Q7-7 | 周线如何切分：自然周（周一到周五）还是按交易日聚合？ | **直接采用东财周 K 接口（`klt=102`）返回的周线**，不自行聚合日线；周线日期为该周最后一个交易日 |
| Q7-8 | 当前周未收盘时，周线用最新价还是上周收盘价？ | **含本周**：本周周线收盘价用实时行情最新价覆盖（仅当最新周线日期与行情时间同属一个 ISO 周），周线指标随行情变化 |

补充口径（v1.2 实现约定，详见 `docs/specs/010-home-board/spec.md` §3.5）：

- 复权方式：**前复权 `fqt=1`**，使均线与现价同口径可比；
- 标准差：**样本标准差（除以 N−1）**，对齐通达信/同花顺 `STD`；
- 数据不足：窗口内周线根数 < 指标所需根数 → `--`（`INSUFFICIENT`），禁止用已有根数凑算；
- 异常防护：东财前复权对累计分红极大的老股会返回**负价格**（实测贵州茅台 2001 年周线 −312.68），窗口内任一收盘价 ≤ 0 → 指标 `--`；
- 落库：`stock_weekly_quotes`（V6 迁移），每次同步整窗口覆盖 upsert，避免混用两套前复权基准。

| 性能 | 单股 5 年日线查询 < 500ms |
