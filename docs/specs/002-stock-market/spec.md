# Spec 002 — 股票市场

- 编号：002
- 状态：**approved**
- 版本：v1.0

## 1. 需求

### 1.1 功能

1. **全市场股票列表**：分页展示 A 股（沪 / 深 / 北）。
2. **搜索**：支持股票名称、代码模糊搜索。
3. **交易所筛选**：全部 / 沪市 / 深市 / 北交所。
4. **指标排序**：按任意"可排序"指标升降序（指标来自用户配置，不写死）。
5. **指标筛选**：按任意"可筛选"指标做数值区间筛选（如股息率 ≥ 4）。
6. **加入自选**：列表内一键加/取消自选。
7. **跳转详情**。

### 1.2 列表字段

列表展示哪些指标**完全由用户指标配置决定**（`user_metric_preferences.show_in_watchlist` 或列表场景配置），
后端以 `Map<metricCode, MetricValueDto>` 返回，前端按配置渲染。不允许把字段写死在页面。

示例配置：股票名称、实时价格、涨跌幅、PE-TTM、股息率、利润同比、近3天创60日新低。

### 1.3 移动端交互

- 采用**紧凑型股票行**（StockRow）而非 PC 表格。
- 核心指标双列展示，指标多时换行而不是横向滚动。
- 上拉加载更多（每页 20），下拉刷新。
- 数字等宽对齐；涨红跌绿。

## 2. 边界与规则

| 规则 | 说明 |
|---|---|
| 分页上限 | `size` 最大 100，超出截断 |
| 排序字段校验 | 指标编码必须匹配 `^[a-z0-9_]{1,64}$`，否则忽略该排序 |
| 筛选表达式 | 仅接受 `>=n` `<=n` `>n` `<n` `=n` 及用 `&` 组合，非白名单直接丢弃 |
| 无数据处理 | 指标无值时返回 `status=MISSING` + `displayValue="--"`，不参与排序时排最后（NULLS LAST） |
| 数据来源 | 行情类指标实时拉取（腾讯批量），其余查 `stock_metric_values` |

## 3. 接口

```
GET /api/v1/stocks?page&size&keyword&exchange&sortMetric&sortOrder&metricFilters
GET /api/v1/stocks/search?keyword&limit
```

## 5. 验收

1. 切换交易所筛选，列表随之变化。
2. 点击任意指标排序，服务端返回该指标排序结果。
3. 修改指标配置（例如关闭"股息率"），列表中不再出现该列，且无需改代码/重新编译。
4. 搜索"茅台"能返回 600519。
5. 加入自选后，自选页可见。
